# 💰 مدیریت خرج و مخارج

یک برنامه‌ی دسکتاپ کامل با پایتون برای مدیریت درآمد، هزینه و پس‌انداز
ماهانه — با رابط کاربری مدرن (تیره) و **تاریخ کاملاً شمسی (جلالی)**.

## امکانات

- **📊 داشبورد**: نمایش درآمد، هزینه و پس‌انداز ماه جاری در کارت‌های
  رنگی + نمودار دایره‌ای تفکیک هزینه‌ها بر اساس دسته‌بندی
- **➕ ثبت تراکنش**: ثبت سریع درآمد یا هزینه با مبلغ، دسته‌بندی،
  توضیحات و تاریخ شمسی (با دکمه‌ی «امروز» برای پر کردن خودکار تاریخ)
- **📜 تاریخچه**: لیست کامل تراکنش‌ها با قابلیت فیلتر بر اساس ماه/سال
  شمسی، نمایش همه‌ی تراکنش‌ها، و حذف هر تراکنش
- **📈 گزارش ماهانه/سالانه**: نمودار میله‌ای مقایسه‌ی درآمد، هزینه و
  پس‌انداز برای هر ۱۲ ماه سال شمسی انتخابی (فروردین تا اسفند)
- ذخیره‌سازی داده‌ها با **SQLite** در فایل `expenses.db` (کنار خود
  اسکریپت) — اطلاعات بین اجراهای مختلف برنامه حفظ می‌شود

## پیش‌نیازها

- Python 3.8 یا بالاتر
- کتابخانه‌ی `tkinter` (معمولاً همراه پایتون نصب می‌شود؛ در لینوکس در
  صورت نبود، با دستور زیر نصبش کنید)

  ```bash
  sudo apt install python3-tk
  ```

## نصب و اجرا

۱. کتابخانه‌های مورد نیاز را نصب کنید:

```bash
pip install -r requirements.txt
```

۲. برنامه را اجرا کنید:

```bash
python3 expense_manager.py
```

## ساختار فایل‌ها

| فایل | توضیح |
|---|---|
| `expense_manager.py` | کد اصلی برنامه |
| `requirements.txt` | لیست کتابخانه‌های موردنیاز |
| `expenses.db` | پایگاه‌داده‌ی SQLite (به‌صورت خودکار در اولین اجرا ساخته می‌شود) |

## نکته درباره‌ی تاریخ شمسی

تاریخ‌ها با کتابخانه‌ی [`jdatetime`](https://pypi.org/project/jdatetime/)
محاسبه و اعتبارسنجی می‌شوند و به فرمت `YYYY-MM-DD` شمسی (مثل
`1405-03-11`) در برنامه وارد و ذخیره می‌شوند.

> کتابخانه‌ی [Doran](https://github.com/amiralibg/Doran) که برای تاریخ
> شمسی معرفی شد، یک کتابخانه‌ی **TypeScript/JavaScript** است و پکیج
> پایتون ندارد؛ به همین دلیل معادل استاندارد پایتونی آن یعنی
> `jdatetime` در این برنامه استفاده شده است.
