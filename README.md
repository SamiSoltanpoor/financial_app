# 💰 مدیریت خرج و مخارج

یک برنامه‌ی دسکتاپ کامل با پایتون برای مدیریت درآمد، هزینه، بودجه و
پس‌انداز ماهانه — با رابط کاربری مدرن (تیره) و **تاریخ کاملاً شمسی
(جلالی)**.

## امکانات

- **📊 داشبورد**: درآمد، هزینه و پس‌انداز ماه جاری در کارت‌های رنگی +
  نمودار دایره‌ای تفکیک هزینه‌ها بر اساس دسته‌بندی + هشدار خودکار در
  صورت عبور از بودجه‌ی هر دسته
- **➕ ثبت تراکنش**: ثبت سریع درآمد یا هزینه با مبلغ، دسته‌بندی،
  توضیحات و تاریخ شمسی (با دکمه‌ی «امروز»)
- **📜 تاریخچه**: فیلتر بر اساس ماه/سال شمسی، نمایش همه‌ی تراکنش‌ها،
  **ویرایش** تراکنش (با دابل‌کلیک روی ردیف یا دکمه‌ی ویرایش)، حذف
  تراکنش، و خروجی گرفتن از لیست به‌صورت **اکسل**
- **🎯 بودجه‌بندی**: تعیین بودجه‌ی ماهانه برای هر دسته‌ی هزینه، با
  نوار پیشرفت زنده (سبز/زرد/قرمز) که میزان مصرف نسبت به بودجه را
  نشان می‌دهد
- **📈 گزارش**: نمودار میله‌ای مقایسه‌ی درآمد/هزینه/پس‌انداز برای
  ۱۲ ماه سال شمسی انتخابی + خروجی **Excel** (خلاصه ماهانه و تمام
  تراکنش‌های سال) + خروجی **PDF** (گزارش کامل با نمودار و جدول)
- **⚙️ پشتیبان‌گیری**: پشتیبان‌گیری خودکار روزانه از پایگاه‌داده،
  پشتیبان‌گیری دستی، و بازیابی از هر نسخه‌ی پشتیبان قبلی
- ذخیره‌سازی با **SQLite** در فایل `expenses.db`

## پیش‌نیازها

- Python 3.8 یا بالاتر
- `tkinter` (معمولاً همراه پایتون نصب است؛ در لینوکس در صورت نبود:
  `sudo apt install python3-tk`)

## نصب و اجرا

```bash
pip install -r requirements.txt
python3 finance.py
```

## کتابخانه‌های استفاده‌شده

| کتابخانه | کاربرد |
|---|---|
| `jdatetime` | تاریخ شمسی (جلالی) |
| `matplotlib` | نمودارهای داشبورد و گزارش |
| `openpyxl` | خروجی Excel |
| `reportlab` | ساخت فایل PDF |
| `arabic-reshaper` + `python-bidi` | نمایش درست حروف فارسی به‌هم‌چسبیده و راست‌به‌چپ در نمودارها و PDF |

## نکته‌ی مهم درباره‌ی فونت فارسی در PDF

کتابخانه‌ی reportlab به‌صورت پیش‌فرض فونت فارسی ندارد. برای اینکه
متن گزارش PDF درست نمایش داده شود:

1. فونت [Vazirmatn](https://github.com/rastikerdar/vazirmatn/releases)
   (فایل `Vazirmatn-Regular.ttf`) را دانلود کنید.
2. آن را **در همان پوشه‌ی** `expense_manager.py` قرار دهید (یا در
   زیرپوشه‌ی `fonts/`).

برنامه به‌صورت خودکار این فونت را پیدا و در PDF از آن استفاده می‌کند.
اگر فونتی پیدا نشود، هنگام ساخت PDF یک هشدار نمایش داده می‌شود.

## بودجه‌بندی چطور کار می‌کند؟

در تب «🎯 بودجه‌بندی» برای هر دسته‌ی هزینه یک عدد به‌عنوان سقف بودجه‌ی
ماهانه وارد کنید و روی «ذخیره‌ی همه‌ی بودجه‌ها» بزنید. این بودجه هر
ماه به‌صورت خودکار با هزینه‌های همان ماه مقایسه می‌شود. اگر هزینه‌ی
یک دسته از بودجه‌اش بیشتر شود، در داشبورد یک هشدار زرد/قرمز نمایش
داده می‌شود.

## پشتیبان‌گیری چطور کار می‌کند؟

- هر بار که برنامه را باز کنید، اگر همان روز (شمسی) هنوز پشتیبانی
  گرفته نشده باشد، یک نسخه‌ی پشتیبان در پوشه‌ی `backups/` ساخته
  می‌شود.
- حداکثر ۲۰ نسخه‌ی پشتیبان نگهداری می‌شود؛ قدیمی‌ترین‌ها به‌صورت
  خودکار حذف می‌شوند.
- از تب «⚙️ پشتیبان‌گیری» می‌توانید هر زمان دستی پشتیبان بگیرید یا
  یک نسخه‌ی قبلی را بازیابی کنید.

## ساختار فایل‌ها

| فایل/پوشه | توضیح |
|---|---|
| `expense_manager.py` | کد اصلی برنامه |
| `requirements.txt` | لیست کتابخانه‌های موردنیاز |
| `expenses.db` | پایگاه‌داده‌ی SQLite (خودکار ساخته می‌شود) |
| `backups/` | نسخه‌های پشتیبان از پایگاه‌داده |
| `Vazirmatn-Regular.ttf` (اختیاری) | فونت فارسی برای PDF |
